# 인사기록 대시보드 (employeecard)

통로이미지 인사총무팀용 **개인별 인사기록 대시보드**입니다. 엑셀 업로드 서식 한 개를 브라우저에 올리면 전 직원 목록과 개인별 인사기록카드, 승격 심사 명단을 볼 수 있습니다.

- 배포 주소: https://employeecard-aio.vercel.app/
- 서버와 DB가 없는 **단일 HTML 파일**(`index.html`)입니다. 엑셀 파일은 브라우저 안에서만 처리되고 외부로 전송되지 않습니다.
- 화면 설정(라이트/다크, 보기 방식)만 브라우저 localStorage에 저장합니다. 인사 데이터는 저장하지 않으며, 새로고침하면 다시 올려야 합니다.

## 사용 방법

1. 상단 **엑셀 파일 선택**으로 업로드 서식(`.xlsx`)을 올립니다.
2. (선택) **사진 폴더 선택**으로 직원 사진이 든 폴더를 지정합니다. 파일명은 `성명.jpg|png`(권장) 또는 `사번.jpg|png`입니다. 동명이인이 없는 것을 전제로 합니다.
3. **기준일**을 정합니다. 근속, 경력, 평가 연도 표시는 이 날짜를 기준으로 계산됩니다.
4. 목록에서 직원을 클릭하면 오른쪽에 개인 창이 열립니다.

엑셀 없이 **샘플데이터로 둘러보기**를 쓰면 가상 데이터(실제 직원 정보가 아닙니다)로 기능을 미리 볼 수 있습니다.

## 주요 기능

- **직원 목록**: 조직도 순서대로 부서별로 묶어 표시하고, 필터와 검색을 지원합니다.
- **요약 카드**: 인원, 입퇴사, 근속, 주의 대상 등을 보여 줍니다.
- **개인 창 탭**: 기본정보 / 발령이력 / 경력·학력·자격 / 평가·보상 / 상벌 / 연도별 주요 이슈. 자격 기록이 없으면 해당 항목은 표시하지 않습니다.
- **업로드 검사**: 누락, 불일치(예: 퇴사일), 코드표에 없는 값 등을 검사해 **검사 결과**로 보여 줍니다.
- **민감 정보 숨김**: 평가, 연봉, 상벌, 이슈 탭과 연봉 관련 평균·인상률, 승격 심사 버튼을 숨깁니다.
- **인사기록카드 인쇄**, **라이트/다크 모드**.
- **승격 심사**: 6/30, 12/31 기준 승격 대상자 명단을 판정하고 엑셀 다운로드와 인쇄를 지원합니다. 화면에서 입력한 **인사총무팀 의견**이 엑셀과 인쇄물에 들어갑니다(저장되지 않아 새로고침하면 지워집니다).

## 표시·계산 규칙

- 퇴사일과 경력 종료일은 **마지막 근무일**로 보고 해당일까지 포함해 계산합니다.
- 경력은 기간이 겹치면 합치고, 인정비율이 다르면 높은 쪽을 적용합니다. 인정비율이 비어 있으면 100%입니다.
- 01_기본정보의 이전경력(년/월)이 있으면 03_경력 합계보다 우선합니다. 03_경력은 최대 5건까지 표시하고, 초과하면 경고합니다.
- 평가와 연봉은 기준연도 포함 최근 5개년만 표시합니다. 승진, 승격, 상벌, 이슈는 누적 표시합니다.
- 직전연봉과 입사연봉은 기준연도와 그 전년도 입사자만 표시합니다.
- 근속 기념 배지는 다음 해에 근속 10년 또는 20년에 도달하는 경우에만 표시합니다.

### 승격 심사 기준

기준값은 업로드 서식의 `_승격기준` 시트에서 읽습니다. 현재 적용 중인 기준은 아래와 같습니다.

| 현직급 | 승격 후 | 경력 요건 | 평가 요건 |
|---|---|---|---|
| CL1 | CL2 | 당사 근속 36개월 이상 | 직전 2년 평균 70점 이상 |
| CL2 | CL3 | 총경력 96개월 이상 | 직전 3년 평균 80점 이상 |
| CL3 | CL4 | 총경력 180개월 이상 | 직전 3년 평균 80점 이상 |
| CL4 | - | 해당 없음 | - |

- 점수 환산: S=100, A=90, B=80, C=70, D=60
- 6월 심사는 직전연도까지, 12월 심사는 당해 평가까지 반영합니다. 평가 연수가 모자라면 미충족으로 판정합니다.
- 체류연수 제한은 없습니다. 휴직기간은 경력에 포함합니다.
- 임원(대표이사, 전무, 이사), 계약직, 시용직, 퇴직자는 명단에 넣지 않습니다. 휴직자와 CL4는 명단에 넣되 "미해당"으로 표시합니다.
- 과거 6직급 체제의 직급은 `_승격기준` 시트의 매핑으로 현행 CL에 대응시킵니다(사원=CL1, 주임·대리=CL2, 과장·차장=CL3, 부장=CL4). 같은 CL 안에서의 승격은 직전 승격일자를 갱신하지 않습니다.

## 업로드 서식

시트 구성은 업로드 서식(v8)을 따르며 `01_기본정보`, `03_경력` 등과 코드표(`_코드`), 승격기준(`_승격기준`)을 사용합니다. 서식 파일과 `_승격기준` 시트 샘플은 담당자에게 문의하세요.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 배포용 단일 HTML. 앱 코드, 가상 샘플데이터, 엑셀 라이브러리([xlsx-js-style](https://github.com/gitbrent/xlsx-js-style))가 모두 들어 있습니다. |

`main` 브랜치에 올리면 Vercel이 자동으로 배포합니다.

## 개인정보 유의사항

- 저장소와 `index.html`에는 실제 직원 데이터가 없고, 샘플은 모두 무작위로 만든 가상 데이터입니다.
- 실제 인사 데이터가 든 엑셀 파일과 사진은 저장소에 올리지 마세요.
