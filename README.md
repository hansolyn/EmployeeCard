# 인사기록 대시보드 (employeecard)

인사총무팀용 **개인별 인사기록 대시보드**입니다. 엑셀 업로드 서식 한 개를 브라우저에 올리면 전 직원 목록과 개인별 인사기록카드, 승격 심사 명단을 볼 수 있습니다.

- 서버와 DB가 없는 **단일 HTML 파일**(`index.html`)입니다. 엑셀 파일은 브라우저 안에서만 처리되고 외부로 전송되지 않습니다.
- 화면 설정(라이트/다크, 보기 방식)만 브라우저 localStorage에 저장합니다. 인사 데이터는 저장하지 않으며, 새로고침하면 다시 올려야 합니다.

## 사용 방법

1. 상단 **엑셀 파일 선택**으로 업로드 서식(`.xlsx`)을 올립니다.
2. (선택) **사진 폴더 선택**으로 직원 사진이 든 폴더를 지정합니다. 파일명은 `성명.jpg|png`(권장) 또는 `사번.jpg|png`입니다. 동명이인이 없는 것을 전제로 합니다.
3. **기준일**을 정합니다. 근속, 경력, 평가 연도 표시는 이 날짜를 기준으로 계산됩니다.
4. 목록에서 직원을 클릭하면 오른쪽에 개인 창이 열립니다.

엑셀 없이 **샘플데이터로 둘러보기**를 쓰면 가상 데이터(실제 직원 정보가 아닙니다)로 기능을 미리 볼 수 있습니다.

## 업로드 서식

시트 구성은 업로드 서식(v8)을 따르며 `01_기본정보`, `03_경력` 등과 코드표(`_코드`), 승격기준(`_승격기준`)을 사용합니다. 서식 파일과 `_승격기준` 시트 샘플은 담당자에게 문의하세요.

## 개인정보 유의사항

- 저장소와 `index.html`에는 실제 직원 데이터가 없고, 샘플은 모두 무작위로 만든 가상 데이터입니다.
- 실제 인사 데이터가 든 엑셀 파일과 사진은 저장소에 올리지 마세요.
